# Multi-Agent AI Project

This project is a simple implementation of a multi-agent AI system using Python.

The idea is to show how different AI agents can work together instead of using a single model for everything.

---

## What this project does

You enter any topic, and the system uses multiple agents to handle different tasks:

* Researcher → finds key points
* Teacher → explains the topic step by step
* Simplifier → converts it into easy language
* Student → writes short notes
* Examiner → creates basic questions

So overall, it works like a small team helping you understand a topic.

---

## Tech used

* Python
* CrewAI
* Gradio
* OpenAI API

---

## How to run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Add your API keys directly in the code (in `app.py`)

3. Run the app:

```bash
python app.py
```

---

## Note

API keys are not included in this repository for security reasons.
You need to add your own keys before running the project.
